# 生意参谋市场排行爬取 · 使用文档

> 面向使用者（运营 / 数据同事）。**推荐用网页表单自己填选提交**（直观可控）；不想动手的话，也可以直接在对话框里跟助手说，助手代做。

---

## 一、这个工具能干什么

一句话：**从淘宝生意参谋「市场 → 市场排行（商品榜）」页，按「类目 + 统计时间 + 店铺类型」批量爬取商品榜数据，导出 Excel。**

典型用途：

| 场景 | 说明 |
|---|---|
| 竞品监控 | 看某类目下热销商品排行、支付买家数、访客数 |
| 选品参考 | 扒某个细分品类的 top 商品，找爆款方向 |
| 大盘分析 | 一次爬多个类目，横向对比市场趋势 |
| 趋势追踪 | 用「时间段」模式，看榜单随时间的变化 |

---

## 二、怎么用（两种方式）

### 方式一：网页表单（推荐 ⭐）

在表单页里**自己动手填选提交**，直观可控：

1. 在「类目」输入框**输入**要爬的类目（每行一个，支持路径）；
2. **选择**「统计时间」（实时 / 7天 / 30天 / 日 / 周 / 月 / 时间段）和「店铺类型」（全部 / 淘宝 / 天猫）；
3. **点击「开始爬取」按钮**提交；
4. 页面下方实时日志看进度，完成后点「📥 下载汇总 Excel」按钮下载。

![截图：表单主界面](images/03-form.webp)

![截图：爬取中（实时日志）+ 完成后下载按钮](images/04-result.webp)

### 方式二：对话框直接说（省事）

不想操作表单的话，直接在对话框里把需求告诉助手，助手全程代做：

1. 告诉助手要爬的**类目、时间、店铺类型**，例如：

   > 「帮我爬『女鞋』类目近 7 天的天猫商品榜」

2. 首次使用会弹出一个浏览器窗口，你**用手机淘宝 App 扫码登录一次**（登录你自己的账号，之后不用再登）。

   ![截图：生意参谋登录页扫码](images/02-login.webp)

3. 助手自动完成爬取，把 Excel 文件发给你。

## 三、表单里要填选的三样信息（= 告诉助手的信息）

### ① 类目（输入）

- 输入要爬的类目，可单个或多个（每行一个）；
- 用 `>` 分隔层级（如 `女鞋 > 休闲鞋 > 德训鞋`）；
- 只填大类（如「女鞋」）也行，会返回该类目下 top300。

### ② 统计时间（选择）

- **实时 / 7天 / 30天 / 日 / 周 / 月 / 时间段**；
- `7天` = 最近 7 天（最常用）；
- `日 / 周 / 月` = 具体某一天 / 某一周 / 某一月；
- `时间段` = 一段日期范围，按「日 / 周 / 月」粒度拆成多个周期逐个爬。

### ③ 店铺类型（选择）

- **全部 / 淘宝 / 天猫**（默认天猫）。

## 四、操作举例

### 举例 1：爬「女鞋」大类近 7 天天猫热销榜（最常用）

- **表单方式**：类目输入 `女鞋`，统计时间选 `7天`（默认），店铺类型选 `天猫`（默认），点「开始爬取」。
- **对话方式**：跟助手说：「帮我爬『女鞋』类目近 7 天的天猫商品榜」。

得到的是女鞋类目近 7 天、天猫店铺、按支付金额（GMV）排序的 top300 商品榜。

### 举例 2：扒细分品类的爆款（多个叶子类目）

- **表单方式**：类目输入三行（`女鞋 > 休闲鞋 > 德训鞋`、`女鞋 > 时装单鞋 > 乐福鞋（豆豆鞋）`、`女鞋 > 休闲鞋 > 老爹鞋`），时间选 `7天`、店铺选 `全部`。
- **对话方式**：跟助手说：「帮我爬这几个类目近 7 天的商品榜（全部店铺）：女鞋 > 休闲鞋 > 德训鞋、女鞋 > 时装单鞋 > 乐福鞋（豆豆鞋）、女鞋 > 休闲鞋 > 老爹鞋」。

助手会三个类目逐个爬、汇总成一个 Excel。

### 举例 3：看一个月的趋势（时间段模式）

- **表单方式**：类目输入 `女鞋 > 休闲鞋`，统计时间选 `时间段` → 粒度「按周」→ 起止日期选好（如 8-01 到 8-31）。
- **对话方式**：跟助手说：「帮我爬『女鞋 > 休闲鞋』过去一个月的榜单，按周出」。

工具会自动按周拆成多个周期逐个爬，Excel 里用「统计日期」列区分每周。

## 五、取数位置说明

数据对应生意参谋这个页面：

**生意参谋 → 市场 → 市场排行 → 商品榜**

| 文档里的概念 | 生意参谋上的位置 |
|---|---|
| 类目 | 页面顶部的类目选择（如「女鞋 > 休闲鞋」） |
| 统计时间 | 页面上的时间维度（实时 / 最近7天 / 30天 等） |
| 店铺类型 | 天猫 / 淘宝 / 全部 切换 |
| 商品榜数据 | 列表里的排名、商品、支付买家数、访客数等 |

也就是说，工具做的，就是把你在页面上**手动点类目、切时间、切店铺、翻页复制**的动作，**自动化批量完成并导表**。

## 六、结果文件说明

导出 Excel，命名：`店铺名_生意参谋市场排行_统计日期范围_序号.xlsx`

例如：`skechers官方旗舰店_生意参谋市场排行_2026-08-24~2026-08-30_001.xlsx`

![截图：结果文件示例](images/06-result.webp)

字段含义：

| 字段 | 说明 |
|---|---|
| 统计日期 | 该条数据对应的统计周期（时间段模式区分周期） |
| 行业排名 | 商品在榜内的排名 |
| 趋势 | 升 N 名 / 降 N 名 / 持平 / 新上榜 |
| 类目名称 | 商品所属类目 |
| 商品名称 / 商品ID / 商品链接 | 商品信息（链接可直接打开天猫详情页） |
| 商品关键词 | 商品核心关键词 |
| 店铺名称 | 店铺名（B2C 为天猫店） |
| 支付买家数 / 访客数 | 交易与流量指标 |

> 说明：免费版单类目最多返回 top300；小众类目不足 300 属正常。

## 七、常见问题

| 问题 | 说明 |
|---|---|
| 类目路径对不上 | 把类目名说准确（和生意参谋里一致），助手能自动搜类目树匹配 |
| 爬不到数据 | 确认你的账号能看生意参谋免费版；确认类目 + 时间 + 店铺类型组合有数据 |
| 时间段模式慢 | 周期多耗时长，可以先小范围试跑，再分批 |
| 要换账号 | 跟助手说「换个账号登录」 |
