# 生意参谋市场排行爬取 · 使用文档

> 面向使用者（运营 / 数据同事）的快速上手文档。看完这篇，你就能自己把生意参谋「市场排行」的商品榜数据批量爬下来、导成 Excel。

---

## 一、这个工具能干什么

一句话：**从淘宝生意参谋「市场 → 市场排行（商品榜）」页，按「类目 + 统计时间 + 店铺类型」批量爬取商品榜数据，导出 Excel。**

典型用途：

| 场景 | 说明 |
|---|---|
| 竞品监控 | 看某类目下热销商品排行、支付买家数、访客数 |
| 选品参考 | 扒某个细分品类的 top 商品，找爆款方向 |
| 大盘分析 | 一次爬多个类目，横向对比市场趋势 |
| 趋势追踪 | 用「时间段」模式，看榜单随时间的变化 |

## 二、快速开始（首次使用，3 步搞定）

### 第 1 步：装 Node.js（只需一次）

- 下载地址：<https://nodejs.org/zh-cn/> ，选 **LTS 长期支持版**，一路「下一步」默认安装。
- 验证：`Win + R` 输入 `cmd` 回车，输入 `node -v` 能打印版本号即可。

### 第 2 步：双击启动

进入工具目录（`app/` 文件夹），**双击 `start.bat`**：

- 首次自动安装依赖（约 1~2 分钟，走国内镜像）；
- 装完自动打开表单页 `http://localhost:8899`；
- ⚠️ **黑色命令行窗口不要关**，关了服务就停。

> 命令行方式：在 `app/` 目录执行 `node server.js`，效果一样（默认端口 8899，避免和 8787 冲突）。

![截图：双击 start.bat 启动](images/01-启动.png)

### 第 3 步：手机淘宝扫码登录（只需一次）

第一次运行自动弹浏览器，停在**生意参谋登录页**：

1. 手机淘宝 App 扫码 → 手机上确认登录；
2. 登录成功后自动保存，**以后免登录**。

> ⚠️ 登录的是**你自己的淘宝账号**，爬的是**你账号能看到的生意参谋免费版数据**。

![截图：生意参谋登录页扫码](images/02-扫码登录.png)

## 三、操作界面详解

登录后回到表单页 `http://localhost:8899`，界面分三块：

![截图：表单主界面](images/03-表单主界面.png)

### ① 输入类目（每行一个，支持路径）

- 直接粘贴类目路径，一行一个，例如：

  ```
  女鞋
  女鞋 > 休闲鞋 > 德训鞋
  女鞋 > 时装单鞋 > 乐福鞋（豆豆鞋）
  ```

- 只填**大类**（如 `女鞋`）也能爬，会返回该类目下 top300；
- 也可以点「▸ 或从类目树勾选」，**搜索类目名 → 勾选**，更省事；
- 点「解析类目」可预览识别结果（确认路径能对上类目）。

> 类目用 `>` 分隔（`＞` 也行），名称要和生意参谋里的一致。

### ② 统计时间

单选：**实时 / 7天 / 30天 / 日 / 周 / 月 / 时间段**

- `7天` = 最近 7 天（默认，最常用）；
- `日 / 周 / 月` = 选具体某一天 / 某一周 / 某一月；
- `时间段` = 选一段日期范围，按「日 / 周 / 月」粒度拆成多个周期逐个爬。

### ③ 店铺类型

单选：**全部 / 淘宝 / 天猫**（默认天猫）。

### ④ 开始爬取

填完点「**开始爬取**」：

1. 自动弹 Chrome，跳到生意参谋，**自动切换时间、店铺类型、翻页抓取**；
2. 页面下方有**实时日志**（黑底），能看到进度；
3. 完成后出现绿色「📥 下载汇总 Excel」按钮，点它下载。

![截图：爬取完成 + 下载按钮](images/04-结果页.png)

## 四、操作举例

### 举例 1：爬「女鞋」大类近 7 天天猫热销榜（最常用）

1. **类目**填：`女鞋`
2. **统计时间**选：`7天`（默认）
3. **店铺类型**选：`天猫`（默认）
4. 点「开始爬取」→ 等几分钟 → 下载 Excel

得到的是女鞋类目近 7 天、天猫店铺、按支付金额（GMV）排序的 top300 商品榜。

### 举例 2：扒细分品类的爆款（多个叶子类目）

想做「德训鞋」「乐福鞋」「老爹鞋」三个细分品类的选品分析：

1. **类目**填三行：
   ```
   女鞋 > 休闲鞋 > 德训鞋
   女鞋 > 时装单鞋 > 乐福鞋（豆豆鞋）
   女鞋 > 休闲鞋 > 老爹鞋
   ```
2. 时间 `7天`、店铺 `全部`；
3. 点「开始爬取」，三个类目**逐个爬、汇总成一个 Excel**。

### 举例 3：看一个月的趋势（时间段模式）

想看「女鞋 > 休闲鞋」过去一个月、按周的变化：

1. **类目**填：`女鞋 > 休闲鞋`
2. **统计时间**选：`时间段` → 粒度选「按周」→ 起止日期选好（如 8-01 到 8-31）
3. 点「开始爬取」，工具自动按周拆成多个周期逐个爬，Excel 里「统计日期」列区分每周。

## 五、取数位置说明

数据对应生意参谋这个页面：

**生意参谋 → 市场 → 市场排行 → 商品榜**

| 文档里的概念 | 生意参谋上的位置 |
|---|---|
| 类目 | 页面顶部的类目选择（如「女鞋 > 休闲鞋」） |
| 统计时间 | 页面上的时间维度（实时 / 最近7天 / 30天 等） |
| 店铺类型 | 天猫 / 淘宝 / 全部 切换 |
| 商品榜数据 | 列表里的排名、商品、支付买家数、访客数等 |

本工具就是把你在这个页面上**手动点类目、切时间、切店铺、翻页复制**的动作，**自动化批量完成并导表**。

## 六、结果文件说明

Excel 导出在 `output/` 目录，命名规则：

```
店铺名_生意参谋市场排行_统计日期范围_序号.xlsx
```

例如：`skechers官方旗舰店_生意参谋市场排行_2026-08-24~2026-08-30_001.xlsx`

字段含义：

| 字段 | 说明 |
|---|---|
| 统计日期 | 该条数据对应的统计周期（时间段模式区分周期） |
| 行业排名 | 商品在榜内的排名 |
| 趋势 | 升 N 名 / 降 N 名 / 持平 / 新上榜 |
| 类目名称 | 商品所属类目 |
| 商品名称 / 商品ID / 商品链接 | 商品信息（链接可直接打开天猫详情页） |
| 商品关键词 | 商品核心关键词 |
| 店铺名称 | 店铺名（B2C 为天猫店） |
| 支付买家数 / 访客数 | 交易与流量指标 |

> 说明：免费版单类目最多返回 top300；小众类目不足 300 属正常。工具会**同时存 xlsx + json 双备份**。

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 双击 `start.bat` 闪退 | 确认装了 Node.js；右键 `start.bat` 记事本打开看报错 |
| 依赖安装失败 | 命令行进 `app/` 执行 `npm install --registry=https://registry.npmmirror.com` |
| 端口被占用 | 改 `app/server.js` 里的端口（默认 8899） |
| 类目路径解析不出来 | 名称要和生意参谋一致；点「从类目树勾选」用搜索更稳 |
| 爬不到数据 | 确认账号能看生意参谋免费版；确认类目 + 时间 + 店铺类型组合有数据 |
| 时间段模式太慢 | 周期多耗时长，建议先小范围试跑，再分批 |
