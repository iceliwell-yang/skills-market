# 多账号数据下载 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）。在对话框里跟助手说一句，助手复用你浏览器里已经登录的账号，批量下载各后台数据并整合成一个 Excel。

---

## 一、这个工具能干什么

一句话：**复用你本机 Chrome 里已经登录的后台账号，按站点配置自动打开各后台下载数据，整合成一个 Excel（每站一个 sheet + 汇总表），全程不碰账号密码。**

典型用途：

| 场景 | 说明 |
|---|---|
| 切账号下载 | 说「登 1 号店下载后台数据」，自动切到对应账号 |
| 批量更新多店 | 一次更新 5 个店铺 / 账号的后台数据 |
| 多后台整合 | 把各后台报表导出，整合成一个 Excel |
| 审计留痕 | 每次下载都有审计报告，记录每步成败 |

> 🔒 **安全说明**：本工具**不接触、不输入、不存储账号密码明文**；登录永远由你手动完成，工具只复用浏览器已存在的登录态，也不读取任何 Cookie / Token / Session 明文。

---

## 二、怎么用（在对话框里说一句就行）

1. 告诉助手要下哪个站点 / 账号，例如：

   > 「帮我登 1 号店把后台数据下载下来」「切到 3 号店铺拉一下数据」「更新 5 个账号的数据整合成一个表」

2. 助手先给你看**执行计划**（目标站点、下载步骤、输出位置），你确认后再执行。

3. 首次使用会打开本机 Chrome（复用你已登录的账号）。**如果某个账号登录态失效了，助手会停下，提示你手动登录一次该站点**，之后重试即可。

4. 完成后助手把整合好的 Excel 和审计报告发给你。

---

## 三、你要提供的信息

### ① 目标站点 / 账号

- 站点编号或名称（如「1 号店」「3 号店铺」）；不明确时助手会列出全部可用站点让你选。

### ② 下载内容

- 要下载哪些报表 / 数据（由站点配置里的下载步骤决定）。

---

## 四、操作举例

### 举例 1：切换账号下载（最常用）

- 跟助手说：「帮我登 1 号店把后台数据下载下来」。

### 举例 2：批量更新多账号

- 跟助手说：「更新 5 个账号的数据，整合成一个表」。助手逐个下载，最后整合成一个 Excel。

## 六、常见问题

| 问题 | 说明 |
|---|---|
| 提示登录态失效 | 某个账号登录过期了，手动登录一次该站点后重试 |
