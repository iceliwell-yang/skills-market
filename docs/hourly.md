# 小米小时报 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）。在对话框里跟助手说一句，助手自动整合阿里妈妈投放 + 生意参谋数据，生成小时报底表。

---

## 一、这个工具能干什么

一句话：**把阿里妈妈（万相台无界版）投放数据 + 生意参谋商品流量/整体数据，按「商品 ID + 日期 + 整点」维度打通汇总，生成 Excel 公式搭建的小时报底表。**

典型用途：

| 场景 | 说明 |
|---|---|
| 更新小时报 | 说「更新一下小时报」，自动拉最新数据出表 |
| 出大家电小时报 | 按品线 / 渠道看投放和流量数据 |
| 投放 + 流量整合 | 把投放明细和商品流量合并出一张表 |
| 看板自动重算 | 底表用公式搭建，改原始数据自动重算 |

---

## 二、怎么用（在对话框里说一句就行）

1. 告诉助手要出哪个店铺、哪个日期的小时报，例如：

   > 「更新一下今天的小时报」「出今天小米官方旗舰店的大家电小时报」

2. 首次使用会弹出浏览器窗口，**分别扫码登录阿里妈妈、生意参谋**（登录你自己的账号，登录态按店铺分开存，之后自动复用）。

3. 助手自动完成三源抓取 + 汇总，把小时报底表 Excel 发给你。

> 说明：本工具**只读抓取**，不改任何投放计划、商品、预算或出价。

---

## 三、你要提供的信息

### ① 店铺

- 要出哪个店铺的小时报（如「小米官方旗舰店」「小米家电旗舰店」）。

### ② 商品范围

- 全部商品（默认），或指定商品 ID 列表（用映射表 / 品线范围）。

### ③ 日期

- 默认当天（实时到当前整点）；也可指定某一天。

---

## 四、操作举例

### 举例 1：更新今天的小时报（最常用）

- 跟助手说：「更新一下今天的小时报」。助手按默认店铺 + 全部商品，拉到当前整点，生成小时报底表发给你。

### 举例 2：出指定品线的小时报

- 跟助手说：「出今天小米官方旗舰店的大家电小时报」。助手只取大家电品线的商品，汇总出表。

### 举例 3：看某个整点的数据

- 跟助手说：「出今天 12 点的小时报底表」。助手按 12 点快照生成。

---

## 五、结果文件说明

助手会发给你一个 Excel 底表，命名：`小米_小米官方旗舰店_2026-09-02_12点_小时报底表.xlsx`

里面包含多个 sheet：数据底表（旧版/新版分流量口径）、四个原始底表（投放 / 分流量老版 / 分流量新版 / 商品整体）、数据字典。结果示例：

![截图：小时报底表示例](images/06-结果文件.webp)

主要字段（数据底表）：

| 字段 | 说明 |
|---|---|
| 系列 | 品线（如「白电 / 冰箱」） |
| 产品 | 单品简称 |
| 标识 | 商品ID + 渠道（另加「商品ID+汇总」行） |
| 花费 / 点击 / 成交金额 / ROI | 来自阿里妈妈投放，按当天 0 点到当前整点累计 |
| 实时付费UV / 实时销量 | 来自生参分流量 |
| 实时总UV / 下单买家数 / 下单金额 | 来自生参分流量 + 商品整体 |
| 手淘访客 / 手淘买家 | 来自分流量「手淘搜索」来源 |

## 六、常见问题

| 问题 | 说明 |
|---|---|
| 提示登录失效 / 取不到数据 | 登录态过期了，跟助手说「重新登录」即可 |
| 商品太多抓得慢 | 指定商品范围（映射表 / 品线），只抓需要的商品 |
| 全站推广渠道实时数据为 0 | 生参分流量里没有全站推广来源，属正常 |
| 要看某天历史数据 | 生参流量是 T+1，指定日期用 `dateType=day` 口径 |
