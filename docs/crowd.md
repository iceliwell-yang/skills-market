# 达摩盘人群圈选 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）。**推荐用网页表单自己填**（直观可控）；不想动手的话，也可以直接在对话框里跟助手说，助手代做。

---

## 一、这个工具能干什么

一句话：**在淘宝达摩盘「自定义圈人」页面，按标签条件（年龄 / 性别 / 消费能力 / 城市等）自动圈选人群，并保存为人群包。**

典型用途：

| 场景 | 说明 |
|---|---|
| 拉新圈人 | 按年龄、性别、消费能力、城市等圈一个目标人群 |
| 老客 / 意向客 | 圈「店铺行为人群」（如近 30 天收藏 / 加购 / 购买过本店） |
| 竞品人群 | 圈「类目行为人群」（全网在某个类目有过行为的人） |
| 组合圈选 | 对多个人群做交集 / 并集 / 差集（排除）组合 |

> ⚠️ 注意：本工具**只圈选并保存人群包，不推送投放**；圈好后你在达摩盘「人群管理」里能看到新人群包正在计算覆盖人数。

---

## 二、怎么用（两种方式）

### 方式一：网页表单（推荐 ⭐）

在表单页里**自己动手填选提交**，直观可控：

1. 在「人群名」输入框**填**人群名称（留空则按条件自动命名）；
2. 在标签条件里**填**标签名 + 选项（标签名有自动补全，选项用逗号分隔，如 `25-29岁,30-34岁`）；
3. **选**块间逻辑和块内逻辑（交集 / 并集 / 差集）；
4. **点「提交圈选」按钮**，稍等片刻即可完成（首次会弹 Chrome 扫码登录）。

![截图：表单主界面](images/03-form.webp)

![截图：圈选完成结果](images/04-result.webp)

### 方式二：对话框直接说（省事）

不想操作表单的话，直接在对话框里把需求告诉助手，助手全程代做：

1. 告诉助手要圈什么人群，例如：

   > 「帮我圈一个 25-34 岁、消费能力高的女性人群」

2. 首次使用会弹出一个浏览器窗口，你**用手机淘宝 App 扫码登录一次**（登录你自己的账号，之后不用再登）。

   ![截图：达摩盘登录页扫码](images/02-login.webp)

3. 助手自动完成圈选，把结果（人群名 + crowdId + 覆盖人数）告诉你。

## 三、你要填的三样信息

### ① 人群名

- 填你想要的**人群名称**（如 `笔电_年龄25-34女性`）；
- **留空**则按「标签_选项」自动命名，见名知意。

### ② 标签条件

- 一个条件 = **一个标签 + 它的选项**（如「用户年龄」选 `25-29岁,30-34岁`）；
- 一个「块」里可放多个条件，块内逻辑用**交集（AND）/ 并集（OR）**；
- 多个「块」之间用**交集（AND）/ 并集（OR）/ 差集（排除 NOT）**组合。

### ③ 交并差逻辑

- **交集（AND）**：同时满足（如「女性」且「25-34 岁」）；
- **并集（OR）**：满足其一（如「收藏过」或「加购过」）；
- **差集（排除 NOT）**：排除某个条件（如「店铺收藏人群 排除 已购人群」）。

## 四、操作举例

### 举例 1：圈一个基础人群（最常用）

- **表单方式**：人群名填 `笔电_年龄25-34女性`，条件填「用户年龄」选 `25-29岁,30-34岁` +「用户性别」选 `女性用户`，块内逻辑「交集」，点「提交圈选」。
- **对话方式**：跟助手说：「帮我圈一个 25-34 岁的女性人群，叫『笔电_年龄25-34女性』」。

### 举例 2：做差集（排除已购）

想圈「收藏过本店、但还没买」的潜客：

- **表单方式**：块一「店铺行为人群 - 收藏」，块二「店铺行为人群 - 购买」，块间逻辑选「差集（排除）」，点提交。
- **对话方式**：跟助手说：「帮我圈『店铺收藏人群』，排除掉『已购人群』」。

### 举例 3：批量圈多个人群

- **对话方式**：跟助手说：「帮我批量圈这几个人群：① 25-34 岁女性；② 消费能力高；③ 近 30 天收藏过本店」。助手会逐个圈好、逐个回报 crowdId。

## 六、常见问题

| 问题 | 说明 |
|---|---|
| 提交后提示「群体名称不能重复」 | 达摩盘同名人群不能重复创建，换个名字或先删掉旧的 |
| 提示「最多可创建 2100 个营销人群」 | 人群池满了，先删掉几个不用的再圈（跟助手说「删掉 XX 人群」） |
| 标签列表为空 / 报登录错 | 登录态过期了，跟助手说「重新登录」即可 |
| 覆盖人数是 0 或偏少 | 达摩盘覆盖人数是异步计算的，等一会刷新再看 |
