# 达摩盘画像爬取 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）的快速上手文档。看完这篇，你就能自己把达摩盘的人群画像数据爬下来、导成 Excel。

---

## 一、这个工具能干什么

一句话：**从淘宝达摩盘「画像透视」页，把「人群 × 画像标签」的分布数据（占比 + 覆盖人数）批量爬下来，导出成 Excel 底表。**

典型用途：

| 场景 | 说明 |
|---|---|
| 人群洞察 | 看某个投放人群的年龄、性别、城市、消费能力等分布 |
| 标签交叉分析 | 一次勾选多个画像标签（四大类共 57 个），一次性取数 |
| 投放策略依据 | 拿到人群画像后，指导人群包投放 / 创意方向 |
| 多人群对比 | 同时填多个人群，逐个爬取后汇总 |

## 二、快速开始（首次使用，3 步搞定）

### 第 1 步：装 Node.js（只需一次）

- 下载地址：<https://nodejs.org/zh-cn/> ，选 **LTS 长期支持版**，一路「下一步」默认安装即可。
- 装完验证：按 `Win + R` 输入 `cmd` 回车，在黑色窗口输入 `node -v`，能打印出版本号（如 `v20.x`）就对了。

### 第 2 步：双击启动

进入工具目录（`app/` 文件夹），**双击 `start.bat`**：

- 首次会自动安装依赖（约 1~2 分钟，走国内镜像，耐心等）；
- 装完自动打开表单页 `http://localhost:8787`；
- ⚠️ **那个黑色命令行窗口不要关**，关了服务就停了。

> 如果你更习惯命令行：在 `app/` 目录执行 `node server.js`，效果一样。

![截图：双击 start.bat 启动](images/01-启动.png)

### 第 3 步：手机淘宝扫码登录（只需一次）

第一次运行会自动弹出浏览器，停在**达摩盘登录页**：

1. 打开手机淘宝 App → 扫一扫，扫屏幕上的二维码；
2. 手机上点「确认登录」；
3. 登录成功后自动保存，**以后不用再登**。

> ⚠️ 关键：登录的是**你自己的淘宝 / 阿里妈妈账号**。爬到的数据，是**你这个账号在达摩盘里能看到的店铺人群数据**，不是你账号能看的店铺就不会有数据。

> ⚠️ **登录态隔天会失效**：如果提交后一直提示「匹配到 0 个人群」或爬不到数据，多半是登录态过期了。在 `app/` 目录下运行 `node login.js` 单独重新登录即可（会弹 Chrome 让你扫码，登录后自动保存）。

![截图：达摩盘登录页扫码](images/02-扫码登录.webp)

## 三、操作界面详解

登录后回到表单页 `http://localhost:8787`，界面就两部分：

![截图：表单主界面](images/03-表单主界面.webp)

### ① 人群名称（输入框）

- 填**你要分析的人群名字**（**必填**，不填会提示错误）；
- 支持填**多个**，用逗号 / 顿号 / 换行分隔；
- 名称要和你达摩盘「人群列表」里的**关键词对应**（模糊匹配，填对关键词即可）。

### ② 画像标签（四大类，勾选）

- 标签按四大类分组：**用户特征、品类特征、渠道特征、私域特征**（共 57 个）；
- 首次已默认勾好 4 个常用标签：**用户年龄、用户性别、城市等级、消费能力等级**；
- 点某个标签 = 勾选，再点 = 取消；每类右上角有「全选 / 全不选」。

> 完整 57 个标签清单，见同目录的 `app/标签清单.md`。

### ③ 开始爬取

填完人群 + 勾完标签，点「**开始爬取**」按钮：

1. 会自动弹出 Chrome 窗口，跳到达摩盘，**自动勾选标签、自动取数**（你看着就行，别关浏览器）；
2. 表单页会**实时显示进度**（如「正在爬 第1个 门锁_类目30天加购2次排已购 · 标签 2/5 用户年龄」），不用一直盯 Chrome；
3. 通常 **1~3 分钟**出结果；
4. 完成后页面显示「✅ 爬取完成」+ 下载链接，点链接下载 Excel。

![截图：爬取完成后结果页](images/04-结果页.webp)

## 四、操作举例

### 举例 1：看「门锁类目加购人群」的基础画像（最常用）

想了解「门锁_类目30天加购2次排已购」这群人的年龄、性别、城市、消费能力，这样操作：

1. **人群名称**填：`门锁_类目30天加购2次排已购_WW`
2. **画像标签**保持默认勾选（用户年龄 / 用户性别 / 城市等级 / 消费能力等级，4 个正好）
3. 点「开始爬取」→ 等 1~3 分钟 → 下载 Excel

结果里就能看到：这个人群里 18-24 岁占多少、25-29 岁占多少、男/女各占多少、一二三线城市占比、消费能力等级分布……

### 举例 2：一次爬多个人群 + 更多标签

想同时对比两个人群、并多看点标签：

1. **人群名称**填两行（或逗号分隔）：
   ```
   门锁_类目30天加购2次排已购_WW
   小家电_净水行业购买
   ```
2. **画像标签**在「用户特征」里额外勾选：**用户职业、教育程度、人生阶段、月均消费金额** 等；
3. 点「开始爬取」，工具会**逐个跑完两个人群**，结果汇总在一个 Excel 里。

## 五、取数位置说明

如果你想知道「这些数据在达摩盘哪个页面能看到」，对应关系如下：

| 文档里的概念 | 达摩盘上的位置 |
|---|---|
| 人群 | 达摩盘后台 → **洞察 → 画像透视**，或「人群列表」里的人群 |
| 画像标签（四大类） | 画像透视页里的「用户特征 / 品类特征 / 渠道特征 / 私域特征」标签 |
| 占比 | 每个标签属性对应的「占比」列 |
| 覆盖人数 | 每个标签属性对应的「人群量级 / 覆盖人数」列 |

也就是说，本工具做的，就是把你在「画像透视」页要**手动逐个勾选标签、逐个看数字**的动作，**自动化批量完成并导表**。

![截图：达摩盘画像透视页（取数位置）](images/05-达摩盘取数位置.webp)

## 六、结果文件说明

Excel 导出在 `output/` 目录，命名规则：

```
店铺名_达摩盘人群画像_日期_编号.xlsx
```

字段含义：

| 字段 | 说明 |
|---|---|
| 人群 | 你填的人群名称 |
| 标签 | 画像标签名（如「用户年龄」） |
| 属性 | 标签下的具体属性值（如「18-24岁」） |
| 占比 | 该属性在人群中的占比 |
| 人群量级 | 覆盖人数 |
| 人群属性占比量级 | 属性对应的人群量级 |
| 店铺 | 店铺名称 |

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 双击 `start.bat` 闪退 | 先确认装了 Node.js；右键 `start.bat` 用记事本打开看报错 |
| 依赖安装失败 | 命令行进入 `app/` 目录，执行 `npm install --registry=https://registry.npmmirror.com` |
| 登录态过期（提示「匹配 0 个人群」/爬不到数据） | 在 `app/` 目录运行 `node login.js` 重新扫码登录 |
| 要换账号重新登录 | 删除 `app/auth.json` 文件重新运行，或运行 `node login.js` |
| 端口被占用 | 改 `app/server.js` 里的 `PORT` 值（默认 8787） |
| 弹出 Chrome 没反应 | 确认电脑装了 Chrome 或 Edge；多等一会，首次取数较慢 |
| 爬不到数据 | 确认当前登录账号在达摩盘里确实能看这个店铺的人群 |
