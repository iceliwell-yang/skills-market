# 达摩盘画像爬取 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）。你**不需要装任何软件、也不需要懂技术**——直接在 WorkBuddy 对话框里跟助手说一句，助手帮你把数据爬好、导成 Excel。

---

## 一、这个工具能干什么

一句话：**从淘宝达摩盘「画像透视」页，把「人群 × 画像标签」的分布数据（占比 + 覆盖人数）批量爬下来，导出成 Excel。**

典型用途：

| 场景 | 说明 |
|---|---|
| 人群洞察 | 看某个投放人群的年龄、性别、城市、消费能力等分布 |
| 标签交叉分析 | 一次看多个画像标签（四大类共 57 个） |
| 投放策略依据 | 拿到人群画像后，指导人群包投放 / 创意方向 |
| 多人群对比 | 同时看多个人群，汇总在一个 Excel 里 |

---

## 二、怎么用（在对话框里说一句就行）

1. 打开 WorkBuddy 对话框，把你要爬的**人群**和**标签**告诉助手，例如：

   > 「帮我爬 XX 店铺的『门锁_类目30天加购2次排已购』人群画像，标签看：用户年龄、用户性别、城市等级、消费能力等级」

2. 首次使用会弹出一个浏览器窗口，你**用手机淘宝 App 扫码登录一次**（登录你自己的账号，之后不用再登）。
3. 助手自动完成爬取，把 Excel 文件发给你。

> 你只需要做两件事：**① 告诉助手要爬什么人群、看哪些标签；② 首次扫码登录一次。** 其余（装环境、运行、取数、导表）全部由助手代劳。

---

## 三、你要告诉助手的两样信息

### ① 人群名称

- 告诉助手要分析哪个人群（可多个，用顿号 / 逗号分开）；
- 名称用达摩盘「人群列表」里的关键词（模糊匹配，说对关键词即可）。

### ② 画像标签

- 四大类共 **57 个**标签，想看哪些维度就报哪些；
- 常用 4 个：**用户年龄、用户性别、城市等级、消费能力等级**。

---

## 四、操作举例

### 举例 1：看基础画像（最常用）

在对话框里说：

> 「帮我爬『门锁_类目30天加购2次排已购_WW』的画像，看用户年龄、用户性别、城市等级、消费能力等级」

结果里就能看到：这个人群 18-24 岁占多少、25-29 岁占多少、男 / 女各占多少、一二三线城市占比、消费能力等级分布……

### 举例 2：一次爬多个人群 + 更多标签

在对话框里说：

> 「帮我爬这两个人群的画像：门锁_类目30天加购2次排已购_WW、小家电_净水行业购买；标签多看几个：用户职业、教育程度、人生阶段、月均消费金额」

助手会逐个跑完，结果汇总在一个 Excel 里。

## 五、取数位置说明

如果你想知道「这些数据在达摩盘哪个页面能看到」，对应关系如下：

| 文档里的概念 | 达摩盘上的位置 |
|---|---|
| 人群 | 达摩盘后台 → **洞察 → 画像透视**，或「人群列表」里的人群 |
| 画像标签（四大类） | 画像透视页里的「用户特征 / 品类特征 / 渠道特征 / 私域特征」标签 |
| 占比 | 每个标签属性对应的「占比」列 |
| 覆盖人数 | 每个标签属性对应的「人群量级 / 覆盖人数」列 |

也就是说，助手做的，就是把你在「画像透视」页要**手动逐个勾选标签、逐个看数字**的动作，**自动化批量完成并导表**。

## 六、结果文件说明

助手会发给你一个 Excel 文件，命名：`店铺名_达摩盘人群画像_日期_编号.xlsx`

字段含义：

| 字段 | 说明 |
|---|---|
| 人群 | 你指定的人群名称 |
| 标签 | 画像标签名（如「用户年龄」） |
| 属性 | 标签下的具体属性值（如「18-24岁」） |
| 占比 | 该属性在人群中的占比 |
| 人群量级 | 覆盖人数 |
| 人群属性占比量级 | 属性对应的人群量级 |
| 店铺 | 店铺名称 |

## 七、常见问题

| 问题 | 说明 |
|---|---|
| 提示「匹配 0 个人群」/ 爬不到数据 | 多半是登录态过期了，跟助手说「重新登录」即可 |
| 要换账号 | 跟助手说「换个账号登录」 |
| 爬不到数据 | 确认你的账号在达摩盘里确实能看这个店铺的人群 |
