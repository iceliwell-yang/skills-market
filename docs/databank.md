# 数据银行画像爬取 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）。**推荐用网页表单自己填**（直观可控）；不想动手的话，也可以直接在对话框里跟助手说，助手代做。

---

## 一、这个工具能干什么

一句话：**从淘宝数据银行（databank.tmall.com）「人群透视」页，把「人群 × 画像标签」的分布数据（占比 + 覆盖人数）批量爬下来，导出成 Excel。**

典型用途：

| 场景 | 说明 |
|---|---|
| 人群洞察 | 看某个品牌人群的性别、年龄、城市、购买力等分布 |
| 标签交叉分析 | 一次看多个画像标签（基础画像 56 个 + 品类行业标签 25 组 302 个） |
| 投放策略依据 | 拿到人群画像后，指导投放 / 创意方向 |
| 多人群对比 | 同时看多个人群，汇总在一个 Excel 里 |

> ⚠️ 注意区分：本工具针对**数据银行**（品牌维度，databank.tmall.com）；要爬**达摩盘**画像用另一个 skill「达摩盘画像爬取」。

---

## 二、怎么用（两种方式）

### 方式一：网页表单（推荐 ⭐）

在表单页里**自己动手填选提交**，直观可控：

1. 在表单里**填**人群名称（支持多个）+ **勾选**画像标签；
2. 点「**开始爬取**」按钮，稍等片刻即可完成（首次会弹 Chrome 扫码登录）。

![截图：表单主界面](images/03-form.webp)

### 方式二：对话框直接说（省事）

不想操作表单的话，直接在对话框里把需求告诉助手，助手全程代做：

1. 告诉助手要爬的**人群**和**标签**，例如：

   > 「帮我爬『手机_K90PM购买_LW』这个人群的数据银行画像，标签看：预测性别、预测年龄、预测城市等级、预测购买力」

2. 首次使用会弹出一个浏览器窗口，你**用手机淘宝 / 天猫 App 扫码登录一次**（登录你自己的账号，之后不用再登）。

   ![截图：数据银行登录页扫码](images/02-login.webp)

3. 助手自动完成爬取，把 Excel 文件发给你。

## 三、你要提供的两样信息

### ① 人群名称 / ID

- 要分析哪个人群（可多个）；支持人群名称模糊匹配，或人群 ID 精确匹配。

### ② 画像标签

- **基础画像**：56 个标签（含性别、年龄、城市、购买力等），其中「预测性别 / 预测年龄 / 预测城市等级 / 预测常驻城市」4 个为固定必选；
- **品类行业标签**：25 组 302 个（如「手机价格段偏好」「美妆品类偏好」等）。

---

## 四、操作举例

### 举例 1：看基础画像（最常用）

- **表单方式**：人群填 `手机_K90PM购买_LW`，勾选「预测性别 / 预测年龄 / 预测城市等级 / 预测购买力」，点「开始爬取」。
- **对话方式**：跟助手说：「帮我爬『手机_K90PM购买_LW』的数据银行画像，看预测性别、预测年龄、预测城市等级、预测购买力」。

### 举例 2：一次爬多个人群

- **对话方式**：跟助手说：「帮我爬这几个人群的数据银行画像：手机_K90PM购买_LW、78149624；标签看预测性别、预测年龄、预测购买力」。助手会逐个跑完，汇总到一个 Excel。

## 五、取数位置说明

数据对应数据银行这个页面：**数据银行 → 人群透视（画像透视）**

| 文档里的概念 | 数据银行上的位置 |
|---|---|
| 人群 | 人群列表（自定义人群）→ 选择人群进入「人群透视」 |
| 画像标签 | 画像透视页的「基础画像 / 消费特征 / 品类特征」标签 |
| 占比 | 每个标签属性对应的「占比」 |
| 覆盖人数 | 每个标签属性对应的人群量级 |

---

## 六、结果文件说明

助手会发给你一个 Excel 文件，命名：`店铺_数据银行人群画像数据_日期_序号.xlsx`

字段含义与结果示例：

![截图：结果文件示例](images/06-result.webp)

| 字段 | 说明 |
|---|---|
| 人群 | 你指定的人群名称 / ID |
| 标签 | 画像标签名（如「预测年龄」） |
| 属性 | 标签下的具体属性值（如「25-29岁」） |
| 占比 | 该属性在人群中的占比 |
| 人群量级 | 覆盖人数 |
| 属性占比的人群量级 | 属性对应的人群量级 |
| 店铺 | 店铺名称 |

## 七、常见问题

| 问题 | 说明 |
|---|---|
| 提示登录失败 / 标签列表为空 | 登录态过期了，跟助手说「重新登录」即可 |
| 要换账号 | 跟助手说「换个账号登录」 |
| 爬不到数据 | 确认你的账号在数据银行里能看这个店铺的人群 |
