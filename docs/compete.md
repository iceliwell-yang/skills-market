# 达摩盘竞争态势分析 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）。**推荐用网页表单自己勾选**（直观可控）；不想动手的话，也可以直接在对话框里跟助手说，助手代做。

---

## 一、这个工具能干什么

一句话：**从淘宝达摩盘「市场 → 竞争分析 → 竞争态势分析」页，爬取各板块数据（含关键词/人群点开的弹窗明细），导出带「统计时间 + 店铺名称」字段的 Excel。**

典型用途：

| 场景 | 说明 |
|---|---|
| 竞争对比 | 看本品 vs 竞品的核心指标、推广指标、经营指标对比 |
| 关键词分析 | 爬 TOP 关键词及其点击量 / 成交笔数 |
| 人群分析 | 爬 TOP 人群及其指标 |
| 渠道结构 | 看付免流量结构、无界投资结构 |
| 客群画像 | 看本品/竞品的客群性别、年龄等画像 |

---

## 二、怎么用（两种方式）

### 方式一：网页表单（三步向导，推荐 ⭐）

在表单页里**自己动手勾选提交**，直观可控：

1. 第一步：**勾选**要爬的板块（核心指标 / 关键词 / 人群 / 客群画像等）；
2. 第二步：**填**共通参数（分析对象级别 + 本品竞品 / 本店竞店 + 时间 + 归因范围）；
3. 第三步：**填**各板块特有参数（关键词板块配词类/指标、人群板块配指标、客群板块配画像标签）；
4. **点「开始爬取」**，完成后页面出现「下载 Excel」按钮。

![截图：表单主界面](images/03-form.webp)

### 方式二：对话框直接说（省事）

不想操作表单的话，直接在对话框里把需求告诉助手，助手全程代做：

1. 告诉助手要爬的店铺、时间、本品竞品、板块，例如：

   > 「帮我爬达摩盘竞争态势分析：小米官方旗舰店，最近 30 天，本品 XX 商品，竞品 A、B、C，看核心指标对比、TOP关键词、TOP人群」

2. 首次使用会弹出一个浏览器窗口，你**用手机淘宝 App 扫码登录一次**（登录你自己的账号，之后自动复用；登录态隔天失效需重新扫）。

   ![截图：达摩盘登录页扫码](images/02-login.webp)

3. 助手自动完成取数，把 Excel 文件发给你。

---

## 三、你要提供的信息

### ① 目标店铺

- 要分析哪个店铺（取数前会校验登录店铺是否一致）。

### ② 分析对象

- **商品级**：本品（一个宝贝）+ 竞品（最多 3 个，超 3 个自动分批）；
- **店铺级**：本店 + 竞店（从达摩盘基准列表里选）。

### ③ 时间 + 归因范围

- 起止日期；归因范围：全域归因 / 广告域归因。

### ④ 要爬的板块

- 核心指标对比 / 竞争控比 / 推广指标对比 / 经营指标对比 / 付免流量结构 / 无界投资结构 / TOP关键词 / TOP人群 / 客群画像。

---

## 四、操作举例

### 举例 1：看本品 vs 竞品核心指标（最常用）

- **表单方式**：勾选「核心指标对比」，商品级填本品 + 2 个竞品，选时间范围，点「开始爬取」。
- **对话方式**：跟助手说：「帮我爬达摩盘竞争态势，小米官方旗舰店，最近 30 天，本品 A，竞品 B、C，看核心指标对比」。

### 举例 2：爬关键词 + 人群

- **对话方式**：跟助手说：「帮我爬竞争态势的 TOP 关键词和 TOP 人群，指标看点击量、当天引导成交笔数」。

## 五、结果文件说明

助手会发给你一个 Excel，命名：`店铺名_竞争态势分析_日期_序号.xlsx`

里面每个板块一个 sheet，宽表格式，所有记录统一带「统计时间」「店铺名称」两列。结果示例：

![截图：结果文件示例](images/06-result.webp)

主要字段（以核心指标对比为例）：

| 字段 | 说明 |
|---|---|
| 统计时间 | 数据统计时间 |
| 店铺名称 | 本品=当前登录店铺，竞品=天猫店铺全称 |
| 商品ID / 商品标题 | 商品级维度（店铺级为店铺名） |
| 点击量 / 成交笔数 | 核心指标（后跟「增长率」列） |
| 点击量控比 | 竞争控比板块 |

## 六、常见问题

| 问题 | 说明 |
|---|---|
| 提示登录失效 / 取不到数据 | 登录态隔天失效，跟助手说「重新登录」即可 |
| 竞品超过 3 个 | 自动分批取数合并，不影响结果 |
| 本品无效 / 取不到数据 | 换一个有效的本品（近 30 天有销量的宝贝） |
| 店铺级竞店选不上 | 竞店只能从达摩盘基准列表里选，不在列表的店铺取不到 |
