# 小时报整合 · 使用文档

> 面向使用者（运营 / 投放 / 数据同事）。整合阿里妈妈投放 + 生意参谋数据，按小时生成看板，可推送钉钉。

---

## 一、这个工具能干什么

一句话：**把阿里妈妈（万相台无界版）投放数据 + 生意参谋流量/整体数据，按「商品ID + 日期 + 整点」打通，生成小时报底表（Excel），并支持一键推送到钉钉在线表格。**

典型用途：

| 场景 | 说明 |
|---|---|
| 投放复盘 | 看每个渠道（直通车 / 引力魔方 / 万相台 / 全站推广等）按小时的花费、成交、ROI |
| 商品流量分析 | 看每个商品的流量来源（手淘搜索 / 推荐等）、付费 UV、总 UV |
| 小时级盯盘 | 当天 0 点到当前整点的实时累计数据，按小时更新 |
| 团队同步 | 底表推送到钉钉在线表格，群里同事直接看 |

---

## 二、怎么用

在对话框里直接说，助手全程代做：

- 「更新小时报」—— 按默认店铺 + 全部商品跑当天小时报
- 「出小米家电旗舰店的小时报」—— 指定店铺
- 「拉投放和生参数据，生成看板」—— 拉数 + 汇总 + 出底表

首次使用需要：

1. 用**你自己的淘宝账号**扫码登录阿里妈妈（万相台无界版）；
2. 扫码登录生意参谋（**注意选对店铺**）。

登录态会保存复用，之后不用重复扫码。

---

## 三、输出什么

生成一个 Excel 底表，包含多个 sheet：

- 数据底表（旧版分流量 / 新版分流量两个口径）：商品 × 渠道的当前整点快照
- 原始底表：投放、分流量老版、分流量新版、商品整体（对账用）
- 数据字典：每个字段的来源和口径说明

可选：一键推送到钉钉在线表格（覆盖写入）。

---

## 四、数据口径说明

- 投放字段（花费 / 成交 / ROI 等）：来自阿里妈妈，按当天 0 点到当前整点累计。
- 分流量（付费 UV / 销量、总 UV / 销量）：来自生意参谋，**T+1 数据**（今天的数据明天才有），底表用最近可用口径并标注。
- 商品整体（下单买家数 / 金额）：来自生意参谋实时数据。

---

## 五、常见问题

- **登录后没数据？** 确认生意参谋登录的店铺是对的（sn 要等于目标店铺）。
- **分流量是空的？** 分流量是 T+1，当天数据还没生成属正常，用最近一天的数据。
- **要换店铺 / 只跑部分商品？** 直接跟助手说，比如「跑 XX 店铺的这几个商品」。
