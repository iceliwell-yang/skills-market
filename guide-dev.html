开发 Skill

在 WorkBuddy 里创建一个自己的技能（Skill）

给自己的 WorkBuddy 加个专属技能

Skill 是 WorkBuddy 的「能力包」——装一个就多一项本事。下面 3 步，教你从零创建一个自己的 skill。

1
进入技能页，找到「创建技能」入口
点击侧边栏 「专家·技能·连接器」 → 切到 「技能」，点右上角 「+ 添加技能」，会弹出三个入口：查找技能 / 上传技能 / 创建技能。
2
召唤「Skill 制作顾问」专家
切到 「专家」，在搜索框搜 「Skill 制作顾问」，召唤这位专门帮你制作 skill 的专家。
3
在对话框里描述功能，生成 skill
专家会调用 skill-creator 引导你：在对话框里输入 请帮我创建一个可以实现「……」的 skill，再按提示填写「该 skill 要什么功能」，描述清楚后它就会自动帮你生成。
💡 描述功能时越具体越好（比如「爬取某网站的数据并导出 Excel」），skill-creator 就能生成更贴合你需求的技能。
✕ 点击任意处关闭
