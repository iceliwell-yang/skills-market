把 DeepSeek 等第三方模型接入 WorkBuddy

给 WorkBuddy 接入自己的模型

WorkBuddy 支持接入 OpenAI 兼容协议的第三方模型（如 DeepSeek、通义、智谱等）。按下面 3 步，把模型地址和 Key 填进去就能用。

1
打开「设置」
点击 WorkBuddy 左下角的 「设置」（齿轮图标）。
2
进入「模型 → 自定义模型」
在设置左侧菜单点 「模型」，再切到 「自定义模型」，点右上角 「+ 添加模型」。
3
填写模型信息并保存
在弹出的「添加模型」弹窗里依次填写：
  • API 地址：填入模型服务商的接口地址（示例为 DeepSeek 的 https://api.deepseek.com/chat/completions）；
  • 提供商：选择对应服务商（如「深度求索 / DeepSeek」）；
  • API Key：填入你在服务商后台申请的密钥；
  • 模型名称：填入模型 ID（如 DeepSeek-V4 Pro）。
填完点 「保存」，模型就会出现在聊天输入框下方模型下拉的「自定义模型」分组里。
✕ 点击任意处关闭
